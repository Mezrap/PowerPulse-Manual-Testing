# Yetkili Kullanıcı – Profil Ayarları

**Modül Kodu:** `AU-PS`

---

## 🎯 Bu Modülün Amacı

Bu modül, yetkili kullanıcıya ait **Profile Settings** sayfasındaki UserForm ve UserCard bileşenlerinin doğrulanmasını kapsamaktadır. Modül içerisinde profil bilgilerinin görüntülenmesi, alan doğrulama kuralları, zorunlu alan kontrolleri, Save butonunun davranışı ve UserForm ile UserCard bileşenlerinin responsive yerleşimleri test edilmiştir.
