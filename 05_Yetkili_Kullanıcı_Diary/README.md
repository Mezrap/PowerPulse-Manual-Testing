# Yetkili Kullanıcı – Diary

**Modül Kodu:** `AU-DR`

---

## 🎯 Bu Modülün Amacı

Bu modül, yetkili kullanıcıya ait **Diary** sayfasının kullanıcı arayüzü, tarih seçimi, ürün ve egzersiz kayıtlarının görüntülenmesi, DayDashboard hesaplamaları, günlük özet bilgilerinin güncellenmesi, iş kurallarının doğrulanması ve responsive tasarım davranışlarının test edilmesini kapsamaktadır. Ayrıca Dashboard üzerinde görüntülenen kalori ve fiziksel aktivite bilgilerinin uygulama üzerinden gerçekleştirilen işlemler ve API doğrulamaları ile doğru şekilde güncellendiği doğrulanmıştır.
